# Custivio Page Permission Matrix

Report date: 2026-05-22

| Page            | Required permissions                          | Data APIs                                                  | Mutation APIs                               | Current status      | Notes                                                          |
| --------------- | --------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------- | ------------------- | -------------------------------------------------------------- |
| Login           | Public                                        | `POST /api/auth/login`, `GET /api/auth/me`                 | `POST /api/auth/login`                      | COMPLETE            | Cookie session only.                                           |
| Dashboard       | Authenticated                                 | Assets, stock, custody, maintenance, audits                | None                                        | COMPLETE            | Cards are permission-aware through API availability.           |
| Assets          | `assets.read`                                 | `GET /api/assets`, catalog/location/user data as permitted | `POST /api/assets`                          | COMPLETE            | Create uses backend-supported asset fields.                    |
| Asset detail    | `assets.read`                                 | `GET /api/assets/{id}`                                     | Patch, lifecycle, attachments               | COMPLETE            | Edit exposes backend asset fields; QR print uses real payload. |
| Catalog         | `catalog.manage`                              | Catalog/location lists                                     | Catalog/location create/update/archive      | COMPLETE            | Prompt editing removed.                                        |
| Stock           | `inventory.read`                              | `GET /api/stock/items`                                     | Stock unit/item/movement creates            | COMPLETE            | Idempotency key used for movement.                             |
| Custody         | `custody.read`                                | `GET /api/custody/checkouts`, transfer data                | Checkout/checkin/handover/transfer/decision | COMPLETE            | Handover requires explicit target user.                        |
| Maintenance     | `maintenance.read`                            | Tickets and warranties                                     | Ticket/status/warranty creates              | COMPLETE            | Backend-backed.                                                |
| Audit & Reports | `audits.read`, `imports.read`, `reports.read` | Campaigns, import jobs, export jobs, saved filters         | Audit scan, import, export, saved filter    | COMPLETE            | Import/export no longer uses hardcoded demo payloads.          |
| Users           | `users.manage`                                | `GET /api/admin/users`                                     | Create/update/reset/disable                 | COMPLETE            | Backend admin API.                                             |
| Roles           | `roles.manage`                                | `GET /api/admin/roles`                                     | Create/update roles                         | COMPLETE            | Permission checkbox editor.                                    |
| Assignments     | `roles.manage`                                | Users, roles, assignments                                  | Create/delete assignment                    | COMPLETE_WITH_NOTES | Scope ID selection remains text/tenant focused.                |
| Status          | Authenticated                                 | Health, ready, ops, metrics, OpenAPI                       | None                                        | COMPLETE            | Backend status APIs are rate limited where appropriate.        |
