# Revised Phase Plan

## Phase 1: Governance And Scaffold

Create the monorepo, governance files, base packages, health endpoints, Docker Compose dependencies, initial Drizzle schema, migration, and seed.

## Phase 2: Database Foundation

Expand tenant, organization, location, user, role, permission, asset catalog, and audit schema modules.

## Phase 3: Auth, RBAC, And Tenant Isolation

Implement login, sessions, permission checks, tenant guards, user management, and security audit events.

## Phase 4: Asset Catalog

Implement configurable asset categories, types, custom fields, manufacturers, models, and vendors.

## Phase 5: Asset Registry

Implement asset CRUD, identifiers, attachments, lifecycle events, and QR/barcode payloads.

## Phase 6: Stock And Consumables

Implement consumable/spare/cable stock, units, bins, ledger, adjustments, transfers, and low-stock rules.

## Phase 7: Custody, Movement, And Maintenance

Implement check-out/check-in, handovers, movement history, maintenance tickets, warranty, repair, and downtime tracking.

## Phase 8: Audit, Import/Export, And Reporting

Implement audit campaigns, scanning, findings, imports, exports, saved views, and reporting.

## Phase 9: Production Hardening

Implement backup/restore, release runbooks, security hardening, dashboards, air-gap bundle docs, and UAT coverage.
