## Shared Adapter Behavior To Preserve

- All JSON route errors use `toErrorResponse` in `apps/web/lib/api/responses.ts`.
- Auth routes use JSON when `Accept` includes `application/json`; otherwise login/logout preserve browser redirects.
- Login sets `custivio_session` as `httpOnly`, `sameSite: "lax"`, `path: "/"`, and uses a secure cookie only for HTTPS.
- Most routes add `x-request-id` on successful responses and handled errors.
- Multipart upload currently buffers the file into memory through `File.arrayBuffer()` before `uploadAssetAttachmentForSession`.
