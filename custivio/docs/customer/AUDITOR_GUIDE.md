# Custivio Auditor Guide

## Purpose

Auditors review assets, custody, stock, reports, audit campaigns, scan results, and exported evidence.

## Audit Campaign Workflow

1. Open **Audit & Reports**.
2. Create an audit campaign with a clear name and scope.
3. Use **Scan** to submit scan codes, result status, notes, and findings when supported.
4. Review campaign and scan status in the campaign table.

## Evidence And Reports

1. Use saved filters for repeatable reporting.
2. Create export jobs from **Audit & Reports**.
3. Wait for completed status.
4. Download the export file.

## Access Limits

Auditors should not mutate admin users, roles, or catalog configuration unless explicitly assigned those permissions.
