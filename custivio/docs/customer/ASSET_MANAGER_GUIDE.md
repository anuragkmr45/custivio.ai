# Custivio Asset Manager Guide

## Purpose

Asset managers maintain the asset registry, attachments, lifecycle events, catalog records, stock visibility, custody, and maintenance coordination.

## Asset Workflow

1. Confirm required catalog data exists: category, asset type, manufacturer, model, and vendor.
2. Confirm location hierarchy exists: site, building, floor, room, rack, shelf, or bin as needed.
3. Go to **Assets** and select **Register asset**.
4. Fill asset type, tag, serial number, name, status, condition, location, custodian, and custom fields.
5. Open the asset detail page to edit fields, add lifecycle events, print/download QR, and manage attachments.

## Attachment Workflow

1. Open an asset detail page.
2. Select **Attachments**.
3. Choose a file and wait for the uploading state to finish.
4. Download the file to verify it is retrievable.
5. Delete outdated files when needed.

## Maintenance And Warranty

- Use **Maintenance** to create tickets, start work, resolve tickets, and add warranties.
- Link tickets and warranties to the correct asset.

## Common Problems

| Symptom                       | Action                                                |
| ----------------------------- | ----------------------------------------------------- |
| Duplicate tag or serial error | Search existing assets and use a unique identifier.   |
| Asset type missing            | Ask an admin or catalog owner to create it.           |
| Upload fails                  | Check file size and retry when the network is stable. |
