# Custivio Import Export Guide

## Import Preview And Processing

1. Open **Audit & Reports**.
2. Select **Import preview**.
3. Enter the original filename.
4. Paste or upload valid rows according to the supported import type.
5. Create the preview and review job status.
6. Select **Process latest** when ready.
7. Review processed and failed row counts.

## Export Jobs

1. Open **Audit & Reports**.
2. Select **Export job**.
3. Choose export type.
4. Add filters or select a saved filter.
5. Create the export job.
6. Wait for completed status.
7. Download the export file.

## Saved Filters

Use **Saved filter** for filters that will be reused by auditors, managers, or admins.

## Troubleshooting

| Symptom              | Action                                                     |
| -------------------- | ---------------------------------------------------------- |
| Import preview fails | Check JSON/CSV format and required fields.                 |
| Job stays pending    | Ask an admin to verify worker status.                      |
| Download unavailable | Wait for completed status or retry after checking network. |
