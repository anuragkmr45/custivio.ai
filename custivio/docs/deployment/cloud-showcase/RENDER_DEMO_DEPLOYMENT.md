# Render Demo Deployment

Render free services are acceptable only for temporary demos.

Limitations:

- Free services can sleep.
- Local filesystem is ephemeral and must not store attachments.
- Free PostgreSQL/data options may expire or be unsuitable for long-lived demos.
- Use external PostgreSQL and S3-compatible object storage if using Render.

Custivio production/on-prem deployments should continue using Proxmox or a controlled VM.
