# Common Custivio Operator Tasks

## Create Or Update Users

Use the administration screens for users, roles, and assignments. Confirm the user is assigned to the correct tenant and role.

## Add Catalog Data

Create or update categories, asset types, manufacturers, models, vendors, stock units, and custom fields before bulk asset entry.

## Receive Stock

Create the stock item if needed, then record a receive movement into the correct location key.

## Assign Asset Custody

Open the asset or custody screen, check out the asset to the user, and verify the active custody row.

## Run Audit Campaign

Create an audit campaign, submit scan results, review findings, and export reports for evidence.

## Prepare Backup

Follow `deployment/operations/BACKUP_RESTORE.md` and record restore rehearsal results in the post-sales checklist.
