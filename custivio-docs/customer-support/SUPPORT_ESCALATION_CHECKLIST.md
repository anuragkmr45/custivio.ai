# Custivio Support Escalation Checklist

Collect this before escalating to engineering:

- Customer name and tenant slug.
- Environment type: dev, staging, production, on-prem, Proxmox, air-gapped, or hybrid.
- Affected module: auth, assets, stock, custody, maintenance, audit, import, export, reports, storage, worker, or deployment.
- Request ID, timestamp, user email, and browser/API client details.
- Exact API route or UI screen.
- Response code and short error message.
- Recent deployment, migration, seed, restore, or configuration change.
- Health/readiness status.
- Relevant logs with secrets removed.
- Whether the issue is reproducible with a second user or role.
