# Custivio Onboarding Checklist

- Confirm deployment model and environment ownership.
- Confirm tenant name, admin users, roles, and permission model.
- Confirm location hierarchy: sites, buildings, floors, rooms, racks, shelves, bins.
- Confirm asset categories, asset types, custom fields, vendors, manufacturers, and models.
- Confirm stock units, item types, low-stock thresholds, and location keys.
- Import or enter initial asset register.
- Import or enter initial stock balances.
- Train administrators, inventory clerks, asset managers, and auditors.
- Schedule first backup and restore rehearsal.
- Schedule first audit campaign.
