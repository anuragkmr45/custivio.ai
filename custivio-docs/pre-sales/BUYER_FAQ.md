# Custivio Buyer FAQ

## Is Custivio a full ERP?

No. Custivio is focused on inventory, IT asset operations, custody, maintenance, audits, and reporting. It can become an ERP-lite foundation later, but sales, accounting, procurement, manufacturing, and dispatch are not core workflows today.

## Can Custivio run without internet access?

Yes. The deployment documentation includes offline and air-gapped release flows.

## Does Custivio need third-party SaaS services?

No. Core workflows use PostgreSQL, Valkey, MinIO/S3-compatible storage, Docker Compose, OpenTelemetry, Prometheus, and Grafana.

## Does Custivio support multiple locations?

Yes. It supports sites, buildings, floors, rooms, racks, shelves, bins, and stock location keys.

## Does Custivio support barcode scanning?

QR payload support exists for assets. A complete barcode scanner and label-printing workflow is future scope.
