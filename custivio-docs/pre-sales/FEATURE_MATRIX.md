# Custivio Feature Matrix

| Area | Status | Notes |
| --- | --- | --- |
| Asset registry | Available | Asset tags, serial numbers, model/vendor, location, custodian, lifecycle, attachments, QR payload. |
| Stock ledger | Available | Receive, issue, transfer, adjust, balances, movement ledger, low-stock rules. |
| Multi-location | Available | Sites, buildings, floors, rooms, racks, shelves, bins. |
| Catalog | Available | Categories, asset types, custom fields, manufacturers, models, vendors, stock units. |
| Custody | Available | Checkout, handover, check-in, transfer request approval/rejection. |
| Maintenance | Available | Tickets, events, warranties, status, priority, downtime fields. |
| Audit and reporting | Available | Audit campaigns, scan results, findings, imports, exports, saved filters. |
| RBAC | Available | Administrator, asset manager, inventory clerk, auditor roles and permission checks. |
| Audit logs | Available | Protected mutations write auditable records. |
| Object storage | Available | MinIO/S3-compatible storage for attachments, exports, and evidence. |
| Observability | Available | OpenTelemetry, Prometheus, Grafana, health, readiness, ops status, metrics. |
| On-prem and air-gap | Available | Docker Compose, offline bundle, Proxmox deployment, backup/restore runbooks. |
| Barcode/QR | Partial | QR payload exists; full scanner/label workflow is future scope. |
| Purchase orders | Not included | Vendor catalog exists, but PO and receiving documents are future scope. |
| Sales/orders/dispatch | Not included | Custivio is not a sales order or dispatch system today. |
| Notifications | Not included | Email or external notification workflows are future scope. |
