# Custivio Documentation

Custivio is an on-prem and air-gapped inventory and IT asset management platform for asset registers, stock ledgers, custody, maintenance, audits, imports, exports, and operational reporting.

## Folder Map

- `engineering/` - API contracts, architecture rules, testing gates, roadmap, progress, and feature implementation notes.
- `deployment/` - production, air-gap, Proxmox, backup, restore, rollback, security, and observability runbooks.
- `customer-support/` - operator guidance, common tasks, troubleshooting, FAQ, and escalation checklists.
- `pre-sales/` - product overview, feature matrix, deployment options, security brief, and buyer FAQ.
- `post-sales/` - onboarding, go-live, UAT, maintenance, and backup rehearsal checklists.
- `qa/` - full-system QA evidence, test matrices, role-access checks, and environment runbooks.

## Source Repositories

- Backend/API/deployment: `custivio/`
- Frontend UI: `custivio-web/`
- Shared observability: `shared-observability/`
